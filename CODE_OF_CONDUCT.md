# Code of Conduct

## Our commitment

We want this project to be a welcoming place for everyone, regardless of experience, language, location, caste, ethnicity, gender, religion, disability or background. Contributors and users should be able to ask questions and report problems without fear.

## Expected behavior

- Be respectful and patient.
- Assume good intent, especially when language or context differs.
- Give constructive feedback about the work, not the person.
- Keep discussions focused on making the app useful for real businesses.
- Respect privacy. Do not post real customer data, backups or personal information.
- Credit other people's work when you use it.

## Unacceptable behavior

- Harassment, threats, insults or discriminatory comments.
- Sexualized language or unwelcome attention.
- Publishing someone's private information without permission.
- Deliberately sharing malware, scams or misleading tax advice.
- Repeated disruption of issues, discussions or pull requests.

## Scope

This code applies in all project spaces, including issues, pull requests, discussions and any other communication connected to the project.

## Reporting and enforcement

If you experience or witness unacceptable behavior, report it privately to the maintainer through the contact method on their GitHub profile. Please include what happened and any relevant links.

The maintainer will review reports in good faith and may:

1. ask for a correction or apology,
2. remove or edit comments,
3. close a discussion or pull request,
4. temporarily or permanently block a participant.

Reports will be handled as confidentially as possible. Retaliation against someone who reports a problem is not acceptable.
